# Fila: temas pedidos pelos informativos

Temas que os julgados comentados já marcam (`"caderno": "disciplina#tema"` no conceito), mas que ainda não estão escritos aqui.
O link do julgado para o tema acende sozinho quando o tema for escrito **com exatamente este slug** (a disciplina usa o slug do ramo).

- **Informativos:** antes de marcar um conceito, procure o tema nos `cadernos/*.json` e nesta fila e reaproveite o slug. Se não houver, acrescente o tema aqui (no mesmo PR ou num PR curto).
- **Cadernos:** ao escrever um tema desta lista, use o slug indicado e apague a linha. A ordem dentro de cada disciplina é pelo número de conceitos que pedem o tema; a prioridade real continua sendo a base de incidência.
- Slug publicado nunca muda (os julgados guardam a referência).
